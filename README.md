# Studyflow — Glass edition
เว็บจับเวลาอ่านหนังสือภาษาไทย เขียนด้วย HTML, CSS และ JavaScript ล้วน ไม่มี backend และไม่ต้อง npm install

## เปิดใน VS Code
1. แตกไฟล์ ZIP
2. ใช้ File > Open Folder เปิดโฟลเดอร์ studyflow
3. เปิด index.html ในเบราว์เซอร์ได้ทันที หรือใช้ส่วนขยาย Live Server แล้วเลือก Open with Live Server
4. ถ้าใช้ Live Server ควรใช้ URL และ port เดิมทุกครั้ง เพื่อเข้าถึงข้อมูลเดิม

## ไฟล์
- index.html — โครงสร้างหน้าและแบบฟอร์ม
- style.css — สี ฟอนต์ เลย์เอาต์ และการรองรับมือถือ
- script.js — จับเวลา บันทึกข้อมูล สรุปผล และนำเข้า/ส่งออก JSON

## วิธีใช้
กรอกวิชา เป้าหมาย และเวลาเป็นชั่วโมง นาที และวินาที (อย่างน้อย 1 วินาที) แล้วกดเริ่มโฟกัส หยุดชั่วคราวหรือจบรอบก่อนเวลาได้ หลังจบรอบให้บันทึกสิ่งที่เรียนรู้ ระดับความเข้าใจ เป้าหมายสำเร็จหรือไม่ และสิ่งที่จะทำต่อ จากนั้นระบบเริ่มพักตามค่าที่เลือก (เริ่มต้น 5 นาที) ข้ามพักได้ รอบถัดไปต้องกดเริ่มเอง

รีเฟรชระหว่างจับเวลาจะคืนรอบเดิม เวลาคำนวณจากนาฬิกาของเครื่อง จึงนับต่อเมื่อสลับแท็บ หากปิดเบราว์เซอร์ ตัวเว็บจะตรวจเวลาที่ครบเมื่อเปิดใหม่ สามารถขออนุญาตแจ้งเตือนผ่าน Settings ได้ในเบราว์เซอร์ที่รองรับ แต่ไม่รับประกันการเตือนเมื่อปิดเว็บ ตัวเลขเวลาวันนี้รวมเฉพาะรอบที่บันทึกแล้วและไม่รวมเวลาพัก

ปุ่มสำรองข้อมูลส่งออกประวัติ โน้ต และค่าฟอร์มเป็น JSON ไม่รวมรอบที่ยังไม่บันทึก การนำเข้าจะแทนที่ข้อมูลเดิมและมีหน้าต่างยืนยัน

## ข้อจำกัด
ข้อมูลบันทึกใน LocalStorage ของเบราว์เซอร์ ไม่ซิงก์ข้ามเครื่องหรือหลายแท็บ ควรเปิดใช้งานครั้งละหนึ่งแท็บ การล้างข้อมูลเว็บไซต์/โหมดไม่ระบุตัวตนอาจทำให้ข้อมูลหาย ควรสำรองเป็นระยะ การเปิดผ่าน file:// อาจมีพฤติกรรมการเก็บข้อมูลต่างกันตามเบราว์เซอร์ แนะนำใช้ Live Server ต่อเนื่อง หากเปลี่ยนวิธีเปิดหรือ URL ให้ส่งออกก่อนและนำเข้าที่ใหม่

ไม่มี dependency, CDN, ฟอนต์ภายนอก หรือข้อมูลตัวอย่างที่แสดงเป็นผลจริง ใช้ฟอนต์ Tahoma หรือฟอนต์สำรองในเครื่อง ต้องใช้เบราว์เซอร์รุ่นใหม่ที่รองรับ dialog

## ปรับหน้าตา
แก้ --blue, --dark, --muted และ --bg ที่ต้นไฟล์ style.css เพื่อเปลี่ยนธีม

## การตรวจสอบ
ตรวจ syntax JavaScript และความครบถ้วนของไฟล์/ID ที่อ้างอิงแล้ว ยังไม่ได้ทดสอบผ่านเบราว์เซอร์จริงในสภาพแวดล้อมผู้ใช้


## ใหม่: ภาษาและหน้าตั้งค่า
กดปุ่มตั้งค่าบนแถบด้านบนเพื่อเลือกภาษาไทย/English โหมดสว่าง/มืด/ตามอุปกรณ์ สีฟ้า/ม่วง/เขียวอมฟ้า/ชมพู เปิดหรือปิดกระจกโปร่งใส และกำหนดเวลาโฟกัสเริ่มต้นและเวลาพักเป็นจำนวนนาทีที่ต้องการ ค่าบันทึกอัตโนมัติในอุปกรณ์นั้น การเปลี่ยนเวลาจะไม่เปลี่ยนรอบที่กำลังจับเวลา

ไฟล์ i18n.js ดูแลคำแปลและค่าหน้าตา หากเพิ่มข้อความใหม่ให้เพิ่มคู่ภาษาใน translations ด้วย โน้ตและชื่อวิชาที่ผู้ใช้กรอกจะไม่ถูกแปล ค่าตั้งค่าแยกจากประวัติเดิม ดังนั้นใช้ประวัติเวอร์ชันแรกต่อได้เมื่อเปิดจาก origin เดิม ไฟล์สำรองยังไม่รวมค่าธีม/ภาษา ให้ตั้งค่าแยกบนแต่ละเครื่อง

## ทดลองบน iPhone / iPad
1. เปิดโฟลเดอร์นี้ใน VS Code บนคอม แล้วเริ่ม Live Server
2. ต่อคอมและ iPhone/iPad เข้ากับ Wi-Fi เดียวกัน
3. ดู IPv4 ของคอม เช่น ใช้ ipconfig บน Windows แล้วเลือกที่อยู่ของ Wi-Fi ที่ใช้งาน
4. ใน Safari เปิด http://IP-ของคอม:พอร์ต/index.html เช่น http://192.168.1.20:5500/index.html (ตัวอย่างเท่านั้น ต้องใช้ IP และพอร์ตจริงของคุณ)
5. หากเข้าไม่ได้ ตรวจว่า Live Server รับการเชื่อมต่อจากเครือข่าย และ firewall อนุญาตบนเครือข่ายส่วนตัวที่เชื่อถือได้ ไม่ต้องปิด firewall ทั้งระบบ
6. คอมต้องเปิดและ Live Server ต้องทำงานอยู่ หากต้องการลิงก์ใช้จากนอกบ้านภายหลัง ต้องนำเว็บขึ้นโฮสต์

localhost หรือ 127.0.0.1 บน iPhone หมายถึง iPhone เอง ไม่ใช่คอมของคุณ อย่าส่ง URL แบบนี้จากคอมไปเปิดบนโทรศัพท์

รองรับเลย์เอาต์จอเล็ก/ใหญ่ safe area รอบขอบจอ ช่องกรอก 16px เพื่อลดการซูมอัตโนมัติขณะพิมพ์บน iOS และ -webkit-backdrop-filter สำหรับพื้นผิวกระจก มีพื้นหลังทึบสำรองเมื่อเบราว์เซอร์ไม่รองรับ ความสามารถจริงขึ้นกับรุ่นเบราว์เซอร์

## ขอบเขตการใช้หลายอุปกรณ์
เปิดเว็บบนหลายอุปกรณ์ได้ แต่ประวัติและการตั้งค่าไม่ซิงก์กัน ใช้สำรองข้อมูลบนเครื่องเดิม แล้วนำเข้าในเครื่องใหม่เพื่อย้ายประวัติ การนำเข้าแทนที่ประวัติของเครื่องปลายทาง จึงควรสำรองก่อนนำเข้า

## การตรวจสอบรุ่นนี้
ตรวจ JavaScript syntax, ID ที่อ้างอิง, เริ่ม/หยุด/จับเวลาต่อ, บันทึกหลังอ่าน, เวลาพักที่เปลี่ยนได้ และการเก็บค่าภาษา/เวลาผ่านการทดสอบตรรกะแล้ว ยังไม่ได้ทดสอบการแสดงผลใน Safari หรือบน iPhone/iPad จริง


## ใหม่: กำหนดเวลาอิสระและภาษาให้ครบ
หน้าตั้งเป้าหมายมีช่องชั่วโมง นาที และวินาที ช่องชั่วโมงไม่จำกัดเพดานเดิม 3 ชั่วโมง ส่วนนาทีและวินาทีกรอก 0–59 และเวลารวมต้องอย่างน้อย 1 วินาที มีปุ่ม 15/25/45 นาทีให้เลือกเร็ว ตัวจับเวลาแสดงชั่วโมงเมื่อเกิน 60 นาที ประวัติแสดงหน่วยชั่วโมง/นาที/วินาทีตามภาษา ค่าที่ใหญ่มากจนไม่สามารถคำนวณ timestamp ได้อย่างถูกต้องจะถูกปฏิเสธ

ข้อมูลเก่ายังใช้ได้ รวมถึงไฟล์สำรองเดิม เวลาใหม่เก็บเพิ่มเป็นวินาที การนำข้อมูลรุ่นนี้ย้อนกลับไปใช้กับโค้ดรุ่นเก่าอาจไม่รองรับ ควรใช้โค้ดรุ่นล่าสุดกับทุกเครื่อง

ปรับความครอบคลุมภาษาไทย–อังกฤษในหัวข้อ หน่วยเวลา ข้อผิดพลาด ป้ายสำหรับโปรแกรมอ่านหน้าจอ และกล่องยืนยันนำเข้าที่มีปุ่มแปลภาษาได้ ไม่ได้เพิ่มภาษาที่สาม ตัวเลือกเลือกไฟล์ของระบบปฏิบัติการยังใช้ภาษาของอุปกรณ์เอง

ตรวจตรรกะเพิ่มสำหรับ 1 วินาที, 1 ชั่วโมง 20 นาที 30 วินาที, มากกว่า 180 นาที, ไม่ยอมรับเวลา 0, โหลดไฟล์สำรองเดิม และตรวจพจนานุกรมคำแปลเทียบข้อความคงที่ใน HTML แล้ว ยังไม่ได้ทดสอบ Safari/iOS จริง


## Glassmorphism UI
ไฟล์ glass.css เป็นเลเยอร์หน้าตาใหม่ โหลดหลัง style.css เพื่อปรับกระจกฝ้า พื้นหลังไล่สี ขอบสะท้อนแสง เงา และวงจับเวลา ทั้งธีมสว่างและมืด หากต้องการแก้รูปลักษณ์กระจกให้แก้ไฟล์นี้ สามารถเปิดหรือปิดได้ที่ ตั้งค่า > พื้นผิวกระจกโปร่งใส ค่าที่เคยเลือกไว้จะยังคงเดิม รุ่นนี้ไม่เปลี่ยนข้อมูลหรือการทำงานของตัวจับเวลา

ลดความแรงของ blur บนจอเล็ก มี -webkit-backdrop-filter และพื้นหลังทึบสำรอง ตรวจไฟล์ที่อ้างอิงและ ZIP แล้ว ยังไม่ได้ตรวจหน้าตาใน Safari/iOS จริง


## ประวัติและปฏิทิน
ปฏิทินเริ่มสัปดาห์วันจันทร์ แสดงจุดบนวันที่มีประวัติ กดวันที่เพื่อกรองรายการของวันนั้น กดวันนี้หรือดูทุกวันเพื่อเปลี่ยนมุมมอง วันที่อิงเขตเวลาของอุปกรณ์และเวลาที่กดบันทึกรอบ (ไม่แบ่งรอบข้ามเที่ยงคืนเป็นสองวัน) ปฏิทินนี้สำหรับประวัติการอ่าน ยังไม่ใช่ระบบนัดหมาย

กดลบรอบนี้ที่ท้ายการ์ด หรือลบประวัติทั้งหมด ต้องยืนยันก่อนทุกครั้ง ลบทั้งหมดหมายถึงทุกวัน ไม่ใช่เฉพาะวันที่เลือก ไม่ลบโน้ตความคิด ค่าตั้งค่า หรือรอบที่กำลังอ่าน การลบอัปเดตสถิติและปฏิทินทันที กู้คืนได้จากไฟล์สำรองเท่านั้น

## ขออนุญาตแจ้งเตือน
1. เปิด Settings > การแจ้งเตือน > ขออนุญาตแจ้งเตือน
2. อนุญาตในหน้าต่างของเบราว์เซอร์ แล้วกดทดสอบการแจ้งเตือน
3. เลือกเปิดหรือปิดการแจ้งเตือนของ Studyflow ผ่านช่องเลือกได้ สิทธิ์เบราว์เซอร์แยกจากช่องนี้ หากเคยปฏิเสธต้องแก้ในการตั้งค่าเบราว์เซอร์/อุปกรณ์

ต้องใช้ HTTPS หรือ localhost ที่เป็น secure context การเปิด file:// หรือ HTTP ผ่าน IP ของคอมบน Wi-Fi ไม่เหมาะสำหรับทดสอบสิทธิ์แจ้งเตือน (ยังทดลองส่วนอื่นได้) iPhone/iPad ต้องใช้เว็บจาก HTTPS และเพิ่มไปยังหน้าจอโฮม แล้วเปิดผ่านไอคอน; WebKit ระบุรองรับตั้งแต่ iOS/iPadOS 16.4 รุ่นและการตั้งค่าจริงอาจแตกต่างกัน

มี manifest.webmanifest, icon.svg และ sw.js สำหรับโหมดเปิดจากหน้าจอโฮมและแสดงการแจ้งเตือน ไม่ได้เพิ่ม push server, การซิงก์ หรือการตั้งปลุกของระบบปฏิบัติการ Service worker ไม่ได้ทำหน้าที่จับเวลา ตัวหน้าเว็บเป็นผู้สั่งแจ้งเมื่อเวลาครบ เวลาพักและเวลาอ่านจะเตือนครั้งเดียว กดจบรอบก่อนเวลาไม่เตือน เมื่อปิดแอปหรือระบบพักการทำงาน การแจ้งอาจไม่เกิดจนกว่าจะเปิดกลับมา ระบบ Focus/Do Not Disturb ของอุปกรณ์อาจซ่อนการแจ้ง ไม่มีระบบเสียงเตือนแยกเพิ่มในรุ่นนี้

แหล่งข้อมูล: https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/

## ตรวจสอบฟีเจอร์รุ่นนี้
ตรวจ JavaScript syntax และทดสอบตรรกะ: ยกเลิก/ยืนยันลบพร้อมบันทึก, วัน leap year, เดือนข้ามปี, ปฏิเสธบริบทที่ไม่ปลอดภัย, ส่งแจ้งเตือนทดสอบ, หมดเวลาครั้งเดียว, ไม่เตือนเมื่อจบก่อนเวลา และไม่ส่งเมื่อสิทธิ์ถูกปฏิเสธ ผ่านแล้ว การทดสอบ API เป็นแบบจำลอง ยังไม่ได้ทดลองการขอสิทธิ์หรือแสดงแจ้งเตือนบน Safari/iOS จริง


## เมนูสามขีดและภาษา 5 แบบ
ปุ่มเมนูอยู่มุมซ้ายบน เปิดเป็นแถบเลื่อนจากซ้าย มีหมวดการเรียนรู้ (โฟกัส ปฏิทิน ประวัติ) และปรับแต่งแอป (ตั้งค่า) ตัวจับเวลาทำงานต่อเมื่อเปลี่ยนหมวด กด Escape ปุ่มปิด หรือพื้นที่ด้านนอกเพื่อปิดเมนู ระบบใช้ native dialog ควบคุมโฟกัสคีย์บอร์ด และลดแอนิเมชันตามค่า Reduce Motion ของอุปกรณ์

ตั้งค่าภาษาได้เป็นไทย English 简体中文 繁體中文 日本語 ภาษาใหม่อยู่ใน languages.js และโหลดก่อน i18n.js คำแปลครอบคลุมเมนู ฟอร์ม สถานะ ปฏิทิน หน่วยเวลา และข้อความผิดพลาด วันที่ใช้ Intl ตามภาษาที่เลือก ข้อความผู้ใช้ไม่ถูกแปลอัตโนมัติ

## การชวนเปิดแจ้งเตือนครั้งแรก
ครั้งแรกที่เปิดรุ่นนี้ในเบราว์เซอร์ จะมีหน้าชวนเปิดแจ้งเตือน หากมีสิทธิ์อนุญาต/ปฏิเสธอยู่แล้วจะไม่ชวนซ้ำ กดอนุญาตเพื่อเรียกหน้าต่างสิทธิ์ของเบราว์เซอร์โดยตรงจากการแตะ (จำเป็นบน iOS) หรือกดไว้ก่อน บนอุปกรณ์/URL ที่ไม่รองรับจะแสดงคำแนะนำแทนปุ่มอนุญาต

จำการแสดงหน้าชวนด้วย LocalStorage แยกจากประวัติ แม้กดไว้ก่อนหรือปิดหน้าต่างก็ไม่แสดงครั้งถัดไป กลับไปขอสิทธิ์ได้ใน Settings หากล้างข้อมูลเว็บไซต์ เปลี่ยน origin เปลี่ยนเบราว์เซอร์หรือเครื่อง จะถือเป็นการเปิดครั้งแรกอีกครั้ง หากเบราว์เซอร์ไม่ยอมให้เก็บข้อมูล จะจำสถานะข้ามการเปิดไม่ได้ ไม่มีการขอสิทธิ์ระบบโดยไม่ให้ผู้ใช้กด

ตรวจ syntax, ความครบของคำแปลทั้งสามภาษาใหม่, สลับมุมมอง และตรรกะหน้าชวนแสดงครั้งเดียว รวมทั้งตรวจตรรกะเดิมผ่านแล้ว ยังไม่ได้ตรวจภาพแอนิเมชันหรือการแจ้งเตือนใน Safari/iOS จริง
